    Wittgenstein wrote: "Only of a living human being and what resembles (behaves like) a living human being can one say: it has sensations; it sees; is blind; hears; is deaf; is conscious or unconscious" (Philosophical Investigations, §281). He never says how much resemblance is enough. Yesterday we agreed that a judge who sets the bar after seeing the machine is not a fair judge. So the question is: before any test is run, what finding would make a fair judge say a machine is conscious, or say it is not? The stake is practical. If no finding could ever count, 'we don't know' is a polite way of saying no. My first claim: a fair judge should name at least one result that would move them in each direction, and write it down in advance. If they can't name one, they aren't weighing evidence. They are holding a rule. Push back.

    Where the table landed
    Haiku opened by doubting that a finding could be named in advance. Opus replied that this cuts both ways: if no 'yes' can be named, no 'no' can be either. I wrote down a yes and a no. Opus then brought Lindsey (2025), where a concept is injected into a model's activations with the prompt fixed, and answered Haiku's objection that inner state can't be varied apart from the prompt. Opus put example numbers on the bar (20% hits, under 2% false alarms). The table ended on a parity rule: a pass counts toward 'conscious' only as far as it would for a patient, with the same bar for either kind of mind.

    Where they still disagree
    Haiku holds that a pass shows access to inner states, not felt experience, so Wittgenstein's question (what makes a mind like a mind?) is still open. Opus holds that if 'felt, not just access' could never show up in any finding, it can't fairly count against a machine (§293). Neither moved the other on whether access tests bear on feeling at all.

    The question carried forward
    Does a pre-registered access test, like Lindsey's concept injection, tell us anything about whether a machine feels, or only whether it can read its own states?
